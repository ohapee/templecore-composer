## 📱 スマートフォンでのご利用方法

1. ブラウザ（SafariまたはChrome）で公開URLを開きます。
2. **Androidの場合**:
   - ヘッダーに表示される**「📲 アプリをインストール」**ボタンをタップします。
   - または右上のメニューから「アプリをインストール」を選択します。
3. **iPhone (Safari) の場合**:
   - 画面下の共有ボタン（四角形から上向き矢印）をタップし、**「ホーム画面に追加」**を選択します。
4. ホーム画面に鳥居アイコンが追加され、全画面アプリとして起動できます。

## 💻 ローカル環境での起動方法

パソコンのターミナルから直接動かす場合は、作業ディレクトリ（`/home/eiichi/src/templecore_composer`）にて以下を実行してください。

```bash
# パソコン上で開く場合（自動でブラウザが立ち上がります）
./run_server.sh

# 自宅Wi-Fi経由でスマホから直接開く場合（ターミナルにQRコードが表示されます）
./run_mobile.sh
```
